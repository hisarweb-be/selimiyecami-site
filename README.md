# selimiyecami.be

Statische export van de oude WordPress-site (Hostinger-back-up van 26 oktober 2026), gratis te hosten op Cloudflare Pages: tak `main`, geen bouwstap, uitvoermap `/`.

Aanpassen: open een `index.html` op GitHub, klik op het potlood, pas de tekst aan en klik op **Commit changes**. Cloudflare Pages zet het binnen een minuut live.

Formulieren (contact, donaties) werken niet statisch en zijn vervangen door een mailknop; zie FORMULIEREN.md naast deze map.
